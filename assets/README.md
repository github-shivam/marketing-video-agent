# assets

Drop source images here — e.g. the photo used as a reel's first frame.

Set the path in `.env`:

    VEO_IMAGE=assets/me.jpg

Contents are gitignored, so personal photos never reach version control.

## What makes a good first frame

- **Portrait orientation.** The reel is 9:16; a landscape photo gets cropped.
- **Well lit, face clearly visible**, looking toward the camera.
- **Room around you.** Veo animates the frame, so a tight headshot leaves it
  nowhere to move. Head-and-shoulders or waist-up works better.
- **Uncluttered background** — fewer things for the model to distort.
- JPEG or PNG.
